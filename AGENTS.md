# AIYR Coffee Dorohoi

For frontend changes, apply the installed `emil-design-eng` (Emil Kowalski), `impeccable` and `design-taste-frontend` (Taste Skill) guidance to this site's existing design.

- **Emil Kowalski:** Give pointer presses short, interruptible feedback. Keep keyboard navigation immediate and respect the reduced-motion preference.
- **Impeccable:** Check keyboard focus, accessible control states, and layout at phone, tablet, and desktop widths. Inspect the rendered result in a browser.
- **Taste Skill:** Lead with real café photography and plain Romanian copy. Keep the evergreen and brass palette, shared content edges, and a clear path to the menu and directions.

Edit the source templates and data in `sursa/`. Regenerate the published HTML with `python sursa/genereaza.py`.
